# 配信オリパAI支援（テスト版）

リアルタイム配信でオリパを売っている最中に、**いまの利益率**と
**下ぶれたときにどこまで値下げしてよいか**を出すツールです。

開くには配布された ID とパスワードが要ります。

## 使い方

1. **オリパ一覧**（最初の画面）で `＋ 新しいオリパ`。
   在庫の CSV があれば `CSV から作る`、または画面のどこかにファイルをドロップ。
2. **編集画面**で賞品の内訳（原価／相場／口数）と販売単価を入れる。
   総口数は口数の合計から自動で決まります。ハズレ枠は「通常枠」の行を足してください。
3. `配信画面をひらく` で**配信中**へ。
   - 落札が決まったら **落札金額・口数**（落札者は任意）を入れて `落札を登録` →
     出たカードをその口数ぶん押す。金額は「単価」「合計」を切り替えられます。
   - 定価で売れたときは登録せずにカードを押すだけで、その単価の「即決」として記録されます。
   - 数字キー `1`〜`9` でも押せます。取り消しは `Backspace` か `u`。
4. 上のメーターと右の「値下げ判断」を見ながら価格を決める。
5. 終わったら `配信を終了して記録`。日付とメモを添えるとその回の結果が残ります。

はじめて開くと**デモ用のオリパ**が 1 本入っています。中身は架空のデータなので、
自由に配信を回して試してください。消したければ編集画面の `このオリパを削除` から。

## 見かたのポイント

- **利益率は仕入原価、還元率は相場**で別々に計算しています。
  「自分が損しているか」と「買い手が得に見えるか」を混ぜないためです。
- **残りの濃さ** が 1.00 を下回ると、残りの口の期待値が設計より薄いということ。
  0.80 を切ると赤（大きく下ぶれ）になります。
- 値下げの目安は 4 つ出ます。いちばん大事なのが **「これ以上下げない」**（残り期待値 × 在庫回収率）。
  この線を割る値下げは、売るより在庫として持っておいたほうが得になります。
- **現金損益**は売れ残りを 0 円と見た数字、**在庫込み損益**は売れ残りを回収率で評価した数字です。

## データの扱い

- 入力した内容は**その端末のブラウザにだけ**保存されます（localStorage）。
  サーバには何も送信しません。誰かと共有されることもありません。
- 端末やブラウザを変えると引き継がれません。移したいときは一覧の
  `全体をバックアップ` で JSON に書き出して、移った先で `JSON を読み込み`。
- **アプリが更新されても、入力したデータはそのまま残ります。**
  読み込みに問題が起きた場合も中身を消さずに退避し、画面で知らせます
  （一覧の `自動退避から復元` で戻せます）。
- ブラウザの履歴やサイトデータを消すと入力も消えます。大事な回は書き出しておいてください。
